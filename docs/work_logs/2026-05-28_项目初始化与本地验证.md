## 五、风险项

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| **arm64 vs x86_64 rootfs** | 本地 macOS 构建为 arm64，GitHub runner 为 x86_64，Windows WSL2 多为 x86_64 | CI 中使用 `ubuntu-latest` (x86_64) 构建，本地测试仅验证流程 |
| **hermes-agent 版本兼容** | pinned 版本 (v2026.4.16) 可能有 bug 或 API 变更 | CI 中版本号可配置，通过 env 变量控制 |
| **rootfs 体积膨胀** | full 安装包可能超 2GB，GitHub Release 有单文件 2GB 限制 | 分层策略已就位；如超限可拆分为多个 Release asset |
| **WSL2 端口转发** | WSL2 的 localhost 转发在某些 Windows 版本有 bug | Tauri 中增加重试和超时机制已实现 (30s timeout) |
| **Inno Setup 大文件** | 打包 1-2GB 的 tar.gz 进 EXE 可能导致安装缓慢 | 使用 lzma2/ultra64 压缩；考虑分卷安装 |
| **Python wheel 跨平台** | 某些 wheel 可能无 linux/amd64 预编译版本 | 使用 `--no-binary :none:` 构建；CI 构建环境有 build-essential |
