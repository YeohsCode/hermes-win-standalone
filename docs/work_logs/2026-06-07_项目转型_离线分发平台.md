## 二、战略转型分析

### 转型原因

经调研发现上游 hermes-agent 已提供：

1. **Electron Desktop App** (`apps/desktop/`) — 完整桌面应用，含聊天（不依赖 PTY）、文件浏览、语音、设置管理
2. **PowerShell 一键安装** — `iex (irm https://hermes-agent.nousresearch.com/install.ps1)`，自动安装全部依赖
3. **Tauri Bootstrap Installer** (`apps/bootstrap-installer/`) — 官方 GUI 安装向导
4. **原生 Windows 全功能** — CLI/TUI/Gateway/Dashboard 全部无需 WSL

我们的 Tauri 外壳（`tauri-app/`）本质上是一个功能远不如上游的 WebView 包装器：
- 启动后仅执行 `window.location.href = url`，整个 WebView 变成不如浏览器的浏览器
- Dashboard /chat 标签页因缺少 POSIX PTY 无法输入（上游 Electron App 自有 Chat UI，不走 PTY）
- 无文件浏览、语音、设置界面、自动更新等功能

### 转型后定位

**Hermes Windows Offline Installer** — 面向离线/企业环境的一键安装包

核心差异化价值：
- **完全离线安装** — 上游安装器需联网；我们内含一切
- **组件化选择** — 核心/浏览器自动化/语音 按需选择
- **企业分发** — 单个 .exe，支持 SCCM/GPO 静默部署
- **中文本地化** — 安装界面中文

### 新架构

```
CI 构建流水线
├─ build-runtime-bundle    → hermes-agent 源码 + Python venv + PortableGit
├─ build-electron-app      → 上游 Electron Desktop App (npm run pack → win-unpacked/)
└─ package-installer       → Inno Setup 打包为单个 .exe

安装布局
├─ {Program Files}\Hermes\        ← Electron Desktop App (Hermes.exe)
└─ %LOCALAPPDATA%\hermes\         ← HERMES_HOME
   ├─ hermes-agent\               ← 源码 + venv + .hermes-bootstrap-complete
   └─ git\                        ← PortableGit
```

### Bootstrap 跳过机制

上游 Electron App 首次启动时检测 `isBootstrapComplete()`：
1. 检查 `%LOCALAPPDATA%\hermes\hermes-agent\.hermes-bootstrap-complete` 是否存在
2. 验证 `schemaVersion === 1` 且 `pinnedCommit` 合法
3. 验证 `hermes_cli/main.py` 存在（source root marker）
4. 验证 `venv/Scripts/python.exe` 存在

`setup-hermes.ps1` 在安装后写入符合格式的 marker JSON，使 Electron App 直接使用预装的 runtime。

## 四、发现并修复的问题

### 1. PowerShell 数组索引歧义
`"$targetRoot[all,web]"` 在 PowerShell 中被解释为数组索引而非 pip extras 语法。改用独立变量赋值：
```powershell
$installSpec = "${targetRoot}[all,web]"
```

### 2. `mkdir -p` 在 PowerShell 中不可用
CI 脚本中的 `mkdir -p` 是 bash 语法，改为：
```powershell
New-Item -ItemType Directory -Force -Path $path | Out-Null
```

### 3. `npm --prefix` 与 npm workspaces 不兼容
`npm --prefix apps/desktop run pack` 可能破坏 workspace 依赖解析。改用 `working-directory`:
```yaml
working-directory: hermes-agent/apps/desktop
run: npm run pack
```

### 4. node-pty 需要 Python
Electron 构建依赖 `node-pty`（native addon），编译需要 Python。CI 中增加 `setup-python` 步骤。
